# Scripts (staff kit)

Portable helpers. App repos add product-specific scripts here or under `scripts/testing/`.

| Script | Role |
|--------|------|
| [promote_changelog_shot.py](promote_changelog_shot.py) | Resize a PNG/JPEG into `docs/changelog_shots/` and print the Change_Log **Shot:** line |
| [capture_changelog_tabs.py](capture_changelog_tabs.py) | **Stub** — boot your UI, wait for paint, grab each modified view |
| [score_cc.py](score_cc.py) | McCabe cyclomatic complexity on functions (**≤ 10** target, **> 15** too high) |

See [docs/PROCESS.md](../docs/PROCESS.md) § Screenshots and § Cyclomatic complexity.
