# Skills

**Skills** = playbooks you attach or paste for a *task* (often domain).  
**Staff kit** = always-on process docs (`PROCESS`, `Coding_Standards`, Change_Log norms) at `docs/` root.

| Folder | Contents |
|--------|----------|
| [General/](General/) | Portable playbooks (multi-agent setup, etc.) |
| [Domain/](Domain/) | Product/domain skills — empty in the template |

## Skills vs documentation

| | Skills | Docs (staff kit / app) |
|--|--------|-------------------------|
| **When used** | On demand for a job | Always available; open on demand by pointer |
| **Examples** | “How I want UI screenshots reviewed” | PROCESS, Change_Log, schema |
| **Agents** | Load when task matches | Load only files named by AGENTS / prompt |

Both are Markdown. Skills are **optional depth**; staff kit is **how the project runs**.
